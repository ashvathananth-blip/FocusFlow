# FocusFlow Distraction Shield — Veritas AI Hackathon

Draft release. Do not publish until the owner approves and the exact production origin is configured and verified.

Free manual installation for desktop Chrome. No Chrome Web Store registration or payment required.

1. Download `focusflow-distraction-shield.zip` and extract it.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select the extracted folder containing `manifest.json`.

Reload FocusFlow after installation. Open the extension popup, grant website permissions, then start a focus session. Manual pause keeps blocking active; ending a session removes session blocking. The master switch and optional keep-blocking setting remain available.

The ZIP has `manifest.json` at its root. Attach `public/downloads/focusflow-distraction-shield.zip` and `release/SHA256SUMS` to the release.
