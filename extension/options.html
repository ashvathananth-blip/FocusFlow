Choose which websites are blocked while a FocusFlow session is running. Changes apply to Chrome's blocking rules immediately and stay on this device.

Blocking: checking installed rules

Blocking follows the live session heartbeat. Pausing the timer keeps rules installed; ending the session removes them.

Default blocked websites

Defaults can be disabled but not removed, so the shield always has a baseline.

Custom websites

Add a hostname to block it and its subdomains during sessions.

Enter a hostname only, such as example.com. Do not include https:// or a page path.

Permissions

Chrome host access is granted per website. Missing access means the rule is configured but cannot be enforced. FocusFlow never reads page content.
